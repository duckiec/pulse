# --- Move 6: gRPC + dynamic protobuf reflection (MEMORY.md ADL-0019) ---------
#
# google.golang.org/protobuf — the protobuf RUNTIME: protoreflect, dynamicpb,
# protodesc, protoregistry, protojson. Required because Move 6's mandate is that

google.golang.org/grpc/
